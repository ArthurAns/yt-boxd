Keep commit messages short: one concise subject line only. No body, no Co-Authored-By line.

**Why:** User asked for shorter messages and explicitly said to always remove the Co-Authored-By line.

**How to apply:** Write only the subject line (under 72 chars). No blank line, no body, no attribution trailer.
